# tribute-che-guevara
# 🟥 Tribute Page – Che Guevara

This is a **tribute page** created using **HTML and CSS** to honor the life and legacy of **Che Guevara**, a revolutionary icon.  
The page was designed to be simple yet impactful, using a strong red–black theme and effective typography to highlight his influence.

## 🚀 Project Overview

This tribute page includes:
- A bold **hero section** with Che Guevara’s name and lifespan
- A **centerpiece image** in a powerful red theme
- A meaningful **quote** attributed to Che Guevara
- A concise **biography** detailing his life and impact
- A footer credit to the author
